# データの見方 (AI チャット向けの補足)

このフォルダ (Resources/AIChat) の Markdown は、AI チャットの RawDataAccess Agent が read_document で読む補足文書です。
モジュール定義から分からない業務上の決まりを書きます。デザインプロジェクトの一部なので、デプロイで反映されます。

## このアプリについて

- Codeer.LowCode.Blazor.Extras の機能確認用サンプルです。データはデモ用で、業務上の意味は限定的です。
- 金額はすべて日本円 (税の区分はありません)。

## 経費申請 (ExpenseRequest / expense_requests)

- 1 行が 1 件の申請。金額は amount。
- 承認の状態はこの表には無く、approval_id で承認フロー (ApprovalFlow / approval_flows) を参照します。承認の履歴は approval_histories です。
- 「承認済みの経費」を集計するときは、承認フロー側の状態で絞ります (承認フローの状態の候補値は describe_module で確認してください)。

## タスク管理 (Gantt / GanttTask, TaskBoard, TaskItem, TaskDep)

- task はガントチャートとタスクボードの元データ、task_dep はタスク間の依存 (先行 → 後続)。
- 進捗率は 0〜100 の整数です。

## 売上 (Sales / sales)、得意先 (Customer / customers)、商品 (Product / products)

- 1 行が 1 件の売上明細。金額 (amount) = 数量 (quantity) × 単価 (unit_price)。単価は商品マスタの標準単価 (products.unit_price) から値引きされることがある。
- 「売上高」として集計するのは状態 (status) が完了 (Completed) の行だけ。受注 (Ordered) と出荷 (Shipped) は見込み、取消 (Cancelled) は含めない。
- 期間は売上日 (sale_date、文字列 yyyy-MM-dd)。会計年度は 4 月〜翌 3 月。
- 得意先の地域 (customers.region) と業種 (industry)、商品のカテゴリ (products.category) で切ると傾向が見える。

## 集計の決まり

- 件数を聞かれたら、論理削除の列がある表では削除済みを除いてください。
- 期間の指定が無いときは全期間で集計し、その旨を一言添えてください。
