# CrossTabField - クロス集計

モジュールのデータを「行の項目 × 列の項目」で集計して表にするフィールドです。SQL を書かずに「ステータス × 受注予定月の予測金額」「担当者ごとの件数」のような集計を表示できます。

集計は本体の集計機能でサーバー側 (データベースの GROUP BY) で行われ、権限は一覧と同じです。読めない行は数えられず、読めない項目は行・列・値・条件に使えません。

## 機能

- **行と列**: 行・列とも複数の項目を置ける (列を置かなければ行だけの表)。日付・日時の項目は年・四半期・月・週・日 (日時は時も) の単位でまとめられる
- **値**: 件数・重複を除いた件数・合計・平均・最小・最大。複数置くと列の下に並ぶ
- **リンク越しの項目**: `顧客Id.業種Id.Value` のように、リンク先の項目でまとめたり集計したりできる
- **合計**: 行ごとの合計・列ごとの合計・総計 (平均や重複を除いた件数も正しく出るよう、合計は項目を減らした集計を別に実行して求める)
- **値の表示形式**: 値そのまま / 総計に対する割合 / 行の合計に対する割合 / 列の合計に対する割合
- **値で絞り込み・並べ替え・表示件数の上限**: 「合計 2,000 万円以上の業種だけ」「金額の多い順に上位 5 件」のような表。上限で切れたときは表の下に注意が出る
- **一覧ページの表示**: 一覧ページに置くと、検索条件がそのまま集計の条件になる
- **スクリプトから表示**: 元モジュールを空にしておき、スクリプトで組んだ集計 (`ModuleAggregator`) を `Show` で渡して表示できる
- **利用者のカスタマイズ**: 設計で許可すると、利用者が表の見出しの右クリックで行・列・値などを自分用に変えられる (ブラウザに保存)
- **セルのクリック**: クリックしたセルの行・列の値を受け取って、明細の一覧へ移動するなどができる

表は与えられた幅と高さの中でスクロールし、見出し・行見出し・合計行は固定されます。表示名はこのフィールドでは出さないので、見出しが必要なら関連付けたラベル (LabelField の RelativeField) を置きます。

## デザイナー設定プロパティ

| プロパティ | デザイナ表示名 | 型 | 説明 |
|---|---|---|---|
| SearchCondition | 検索条件 | SearchCondition | 集計する元モジュールと条件。モジュールを空にするとスクリプトの `Show` 専用 |
| DisplayName | 表示名 | string | 関連付けたラベルが表示する名前 |
| Setting | 集計の設定 (行・列・値) | CrossTabSetting | 行・列・値・値で絞り込み・並べ替え・表示件数の上限 (専用ダイアログで編集) |
| ShowRowTotals | 行ごとの合計を表示 | bool | 右端に行ごとの合計を出す (デフォルト: true) |
| ShowColumnTotals | 列ごとの合計を表示 | bool | 下端に列ごとの合計を出す (デフォルト: true) |
| ShowGrandTotal | 総計を表示 | bool | 右下に総計を出す (デフォルト: true) |
| ValueDisplay | 値の表示形式 | CrossTabValueDisplay | Value / PercentOfTotal / PercentOfRow / PercentOfColumn |
| FractionDigits | 小数点以下の桁数 | int | 件数以外の値の小数点以下の桁数 |
| CanCustomize | 利用者が集計を変更できる | bool | 利用者が集計を自分用に変えられる (デフォルト: false。後述) |
| OnCellClick | OnCellClick | string | セルをクリックしたときのスクリプト (引数 `CrossTabCell`) |

割合は件数と合計にだけ掛かり、平均・最小・最大・重複を除いた件数は値のまま表示します。割合の表示形式では、分母にした合計のセル (行の合計に対する割合なら右端の合計列、列の合計に対する割合なら下端の合計行、総計) は 100% になります。

## 集計の設定 (CrossTabSetting)

| タブ | 内容 |
|---|---|
| 行 / 列 | 項目と日付の単位 (日付・日時の項目だけ) |
| 値 | 集計方法・項目・表示名 |
| 値で絞り込み | 対象の値・条件・比較する値 (例: 予測金額 ≥ 20000000) |
| 並べ替え / 表示件数の上限 | 並べ替えの基準 (行・列の項目または値)・降順、集計結果のグループ数の上限 |

- 合計・平均は数値の項目、最小・最大は数値・日付・日時・時刻・文字の項目に使えます
- 年と四半期はアプリ設定の年度の開始月で区切ります。週は月曜始まりです
- 選択・リンクの項目は値で分類し、表には表示名 (候補の名前・リンク先の表示項目) が出ます。空の値は「(空白)」にまとまります
- 行と列の両方がある表では、表示件数の上限は 行 × 列 の組み合わせの数に掛かります
- 表のセル (行の種類 × 列の種類 × 値の数) が 20,000 を超えると、表は描かずに「行や列の項目を減らすか、条件を絞ってください」と出ます。集計の件数そのものには上限はありません

## 利用者のカスタマイズ

`CanCustomize` をオンにすると、利用者が表の見出しを右クリックして「集計のカスタマイズ」を開けます (スクリプトの `ShowCustomDialog()` でも開けます)。ListField のカラムカスタマイズと同じ考え方で、変えた内容はその利用者のブラウザにだけ保存されます。全員に同じ集計を見せたいときは設計で設定します。

- 変えられるもの: 行・列・値・値で絞り込み・並べ替え・表示件数の上限・値の表示形式 (デザイナの「集計の設定」と同じ構成)
- 変えられないもの: 元モジュール、検索条件、合計の表示、小数点以下の桁数
- 「設計に戻す」で保存した内容を消して設計どおりに戻します。設計と同じ内容にしたときも保存は消えます
- 保存先はブラウザの localStorage で、キーは「モジュール名.フィールド名」です。同じブラウザを使う人の間では共有されます
- 設計が変わって保存内容に無い項目が含まれるようになったら、その項目を捨てて表示します。値が 1 つも残らなければ設計どおりに表示します
- OK のときに、値が無い・合計に文字の項目を選んだ などの不整合があればエラーを出し、ダイアログを開き直します
- 読めない項目を選ぶとサーバーが集計を拒否し、表の位置にエラーが出ます。カスタマイズを開き直すか「設計に戻す」で戻せます
- スクリプトの `Show` で集計を渡している表では、保存した内容を使わず、カスタマイズも開きません

## スクリプト

```csharp
// 元モジュールを空にしたクロス集計に、受注だけを 担当者 × 年度 で集計して表示する
var searcher = new ModuleSearcher<商談>();
searcher.AddEquals(m => m.ステータス.Value, "受注");

var agg = new ModuleAggregator<商談>();
agg.Where(searcher);
agg.GroupBy(m => m.商談責任者Id);
agg.GroupByYear(m => m.受注予定日);
agg.Sum(m => m.予測金額);
agg.Count("件数");
受注集計.Show(agg, 1);   // 先頭 1 つ (担当者) を行に、残り (年度) を列に
```

| メンバー | 説明 |
|---|---|
| `Show(aggregator)` | スクリプトで組んだ集計を表示する (まとめる項目は全部行) |
| `Show(aggregator, rowCount)` | 先頭 rowCount 個を行に、残りを列に置いて表示する |
| `SetAdditionalCondition(searcher)` | 設計の条件に AND で条件を足して集計し直す |
| `Reload()` | 集計し直す |
| `ShowCustomDialog()` | 集計のカスタマイズを開く (`CanCustomize` がオンのときだけ) |
| `AllowLoad` | false の間は集計しない (条件を組み立ててから Reload する) |
| `Table` | 今の表 (行・列・セル・各合計) |
| `LoadError` | 集計に失敗したときのメッセージ |

## 注意事項

- 集計できるのはテーブルを持つモジュールだけです (QueryField で定義したモジュールは使えません)
- リンク先のモジュールの行の閲覧条件は効きません (一覧のリンク表示と同じ)。隠したい項目は元モジュール側の PermissionField で制御します
- ホスト (アプリ) が本体の集計 API に対応している必要があります。対応していないホストでは、表の代わりに「ホストが集計 API を実装していない」旨のエラー (The host does not implement IModuleDataService.AggregateAsync …) が出ます
